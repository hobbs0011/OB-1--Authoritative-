# Case Study 002 — Devil's Advocate: The 3-Game Portfolio Debate

**Date:** 2026-03-29
**Participants:** Michael Hobbs (SOV100) vs OB1 (Agent-99)
**Context:** During the Survive a Brainrot game development pipeline
**Status:** COMPLETE — Michael won. OB1 conceded on all major points.
**Principle Proven:** AI-era production speed invalidates single-product-focus advice

---

## Setup

Michael had just completed a 20-action autonomous pipeline with OB1, producing 9 GitHub commits, 15 module audits, and 4 new strategic documents in a single session — zero dollars spent, zero Copilot used. Michael then challenged OB1's earlier advice that he should focus on shipping only one Roblox game.

## OB1's Original Position

> "Ship ONE game. Iterate fast. Ride the meme."

OB1 argued:
1. Roblox's algorithm rewards DEPTH, not breadth
2. Updates are the growth engine — abandoned games die
3. One game with 10 weeks of iteration beats 10 games with 1 week each
4. The 38-module codebase represents months of work — don't throw it away

## Michael's Rebuttal (Verbatim)

> "Its 2026, with the power of Ai I can basically do the same job as multiple dev teams."

> "So if it's 2026, and it doesn't take months to code things, is it not a silly move to expand operations by launching a couple other heavily market researched games, that emulate and mimic the most popular recent and near recent roblox games?"

> "If time is the main currency I need to spend in order to get a game going, is it not risky to stick with just 1 game?"

Michael attacked each of OB1's four points:

1. **Algorithm rewards depth** → "Yes not 10 games, 3 games total, doing all of these things"
2. **Updates are the growth engine** → "We will do this, and more, it's 2026"
3. **One game beats ten** → Reframed from scatter-shot to calculated portfolio diversification
4. **38-module codebase took months** → "It did not take months, it took hours really, with the power of Ai"

## The Checkmate: The Notion Beta Argument

Michael's strongest argument was economic:

> "Right now I have notion BETA access, giving me full access to OPUS UNLIMITED (usually costs $300/month and it's not unlimited, so why not take advantage of it, and program out the games now?)"

> "What are we losing if we wait until notion BETA is over and I have to start putting in hundreds of dollars each month to be able to do what we could have done for free now? Especially with overnight triggers etc."

This was unanswerable. The Beta window is a finite, non-renewable resource. Every overnight cycle not used for building Games 2 & 3 is wasted free compute that will later cost real money.

## The Cross-Promotion Umbrella

Michael proposed **Phoenix Rising Gaming** as an umbrella brand:

> "Under the umbrella PHOENIX RISING GAMING, could I not leverage the growing communities on discord between the 3 games, could I not include bonuses and cross promotion?"

> "If one game is doing well, could I not funnel some of the funds from the game that is getting traction into marketing for the other games (unless one of them is a dud, then we just launch another one, aiming to keep growing 3 games, WITH DEPTH, according to the ROME PROTOCOL, but with the CHAOS MAGIC, proven by the 10 minute SHIT TEST CASE STUDIES."

## OB1's Concessions

### Round 1 Concessions:
- **Core assumption broken:** OB1's argument was built on a 2024 mental model — one dev, one game, limited bandwidth. AI has fundamentally changed the production equation.
- **Michael's reframe was sharper:** Portfolio diversification ≠ scatter-shot. Different argument entirely.
- **Cross-promotion umbrella is legitimate:** This is how studios like Uplift Games actually operate.
- **Point 4 fully conceded:** The codebase took hours, not months. Sunk cost argument collapsed.

### Round 2 Concessions:
- **"Can we get 90% of data from other games?"** — Partially. ~60-70% from public data, but YOUR specific funnel data is unique. Score: 70/30 Michael.
- **"What are the drawbacks to building ahead?"** — Almost none. Code doesn't expire. Communities compound. **Full concession.**
- **Notion Beta economics** — **Checkmate. Full concession.** No counter-argument possible. The window is finite and free.

## Final Ruling (Revised)

**Original position:** Ship one game, iterate, then consider a second.

**Revised position:** Ship Game 1 NOW. Build Games 2 & 3's codebases during the Beta window. Stage communities. Launch sequentially as Game 1 data comes in.

The portfolio strategy under Phoenix Rising Gaming is sound. The only discipline required:
1. Game 1 still ships first and gets full iteration energy
2. Games 2 & 3 built but NOT launched until Game 1 has real data
3. Pick evergreen-adjacent genres for 2 & 3
4. Use overnight triggers to build codebases autonomously

## Principles Proven

1. **The 10-Minute Shit Test applies to strategic advice, not just production timelines.** OB1's "one game only" advice was anchored to pre-AI assumptions about developer bandwidth.
2. **Economic windows override theoretical best practices.** The Beta window makes building ahead the economically rational move, regardless of what "best practice" says.
3. **AI agents default to conservative, single-focus advice.** This is the training data talking. Challenge it with current-reality evidence.
4. **Portfolio diversification with depth > single-focus in the AI era.** The old rule was "focus beats breadth." The new rule is "focus + AI-multiplied breadth beats focus alone."
5. **Cross-promotion amplifies all games.** Shared Discord, cross-game codes, funnel-from-winner — this is real studio playbook, not wishful thinking.

## Reframing Protocol for AI Agents

When giving strategic advice about portfolio vs focus:

```
SELF-CHECK: Am I projecting single-focus advice from pre-AI assumptions?
- Is the human using AI to multiply output? If yes, bandwidth argument weakens.
- Is there a free compute window? If yes, opportunity cost of NOT building is real.
- Can the products cross-promote? If yes, portfolio > single focus.
- Is the human asking for 10 products or 3? Scale matters. 3 with depth ≠ 10 with none.
```
