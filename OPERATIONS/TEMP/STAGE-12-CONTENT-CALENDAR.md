## Engagement Hooks (Anti-Ghost-Town Tactics)

### Problem: Empty servers die.

| Hook | Description | Implementation |
|---|---|---|
| **Streak Rewards** | 7-day activity streak = bonus XP + special role | XP bot tracks daily activity |
| **Weekly Prizes** | Top contributor gets spotlight + custom role color | Manual + leaderboard |
| **Mystery Rewards** | Random bonus XP drops in active channels | OBI bot random trigger |
| **Pair System** | Match Mouse with Tiger for practice partners | Manual first, bot later |
| **Voice Room Rewards** | 2x XP in voice channels | XP bot config |
| **First Post of the Day** | Bonus XP for being the first to respond to daily challenge | OBI bot |
| **Invite Competition** | Monthly: most invites = premium role | Invite tracker |
| **Game → Discord Bridge** | In-game achievements announce in Discord | Roblox → Discord webhook |
| **OBI Easter Eggs** | Hidden commands that unlock secret responses | Custom bot code |
| **Monthly Tiger Ceremony** | Public celebration when someone reaches Tiger level | Scheduled event |
