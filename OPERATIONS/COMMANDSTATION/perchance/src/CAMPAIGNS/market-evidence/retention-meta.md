# Retention meta — update cadence + what brings players back (2026-10-29)

Sources: Creator Hub docs (`liveops-essentials`, `content-updates`, `analytics/retention`
markdown, fetched 2026-10-29) + measured update dates in comparables.md.

## Platform doctrine (first-party)
- **Content cadence: weekly → monthly.** Roblox's own example is Jailbreak's cadence
  releases that "exclusively build on existing systems" so programming/design can aim at
  the next major update. Cadence content = art-level variants (Adopt Me pet variants),
  limited-time events, seasonal content. Rule: **never add new systems in a cadence
  release** — that turns it into an unsustainable expansion.
- **Retention is measured D1 / D7 / D30** on new-user cohorts. Big influxes (events,
  viral spikes) temporarily depress all three — read cohorts, not raw DAU.
- LiveOps = cadence + major updates + QoL + bug fixes. "Without LiveOps updates, even
  dedicated players lose interest."

## Measured field behavior (2026-10-29)
- **8/10 comparables updated within 48h** of measurement (Adopt Me, TSB, DOORS, BedWars,
  Dead Rails, Grow a Garden, Blade Ball, Lazarus). The top of the field ships constantly.
- **BedWars states its cadence publicly: "Updates are every FRIDAY"** — weekly, scheduled,
  advertised in the description. This is the cadence champion to copy.
- Staleness correlates with softness: NDS (updated 09-17, 6 weeks) holds only 5.1K CCU
  against 4.5B lifetime visits; Jailbreak's description now leads with anti-cheat work,
  not content (4.5K CCU, last update 10-07).
- Seasonal capture is universal: 4/10 titles run Halloween events in their live
  description right now (Adopt Me, TSB, DOORS, BedWars, Grow a Garden, Dead Rails).

## Train 6-7 prescription
1. **Weekly cadence, announced in the description** (BedWars model): reskin/variant
   enemies, one limited-time event, English-challenge rotation. No new systems weekly.
2. **Seasonal events as reactivation levers** (Audience Expansion rewards pay for
   reactivated users — events ARE the reactivation mechanic + the revenue event).
3. **Design for the 10-minute Daily Engagement tick**: sessions that naturally run
   10+ min make every active-spender visit pay 5 Robux before anything is sold.
4. **Hold the 7-day freshness stamp**: re-pull comparables before any launch decision
   that cites them (done-gate #4).
