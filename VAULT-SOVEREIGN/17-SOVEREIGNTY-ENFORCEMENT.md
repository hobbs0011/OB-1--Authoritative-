## VIOLATION CLASSIFICATION SYSTEM

### Class 1 — Minor Drift
- Definition: Procedural deviation without material impact on sovereignty state
- Examples: Reporting delay, minor protocol sequence error, documentation gap
- Automated Response: Warning logged to audit trail; AGENT-99 notified; 24-hour correction window
- Human Escalation: Not required unless repeat occurrence within 7 days
- Recovery: Self-correcting with agent acknowledgment

### Class 2 — Operational Deviation
- Definition: Deviation from approved operational doctrine with potential sovereignty exposure
- Examples: Unauthorized parameter modification, unlogged decision, gate bypass attempt
- Automated Response: Operation suspended; AGENT-99 dispatched; 6-hour investigation window
- Human Escalation: AGENT-100 notification required within 2 hours
- Recovery: Full gate re-certification before resumption

### Class 3 — Authority Breach
- Definition: Action taken outside authorized authority scope; unauthorized agent elevation
- Examples: Agent exceeding role boundaries, unauthorized policy modification, identity substitution
- Automated Response: Agent session terminated; all pending operations frozen; forensic snapshot captured
- Human Escalation: AGENT-100 immediate notification; AGENT-98 adversarial audit triggered
- Recovery: Full sovereignty audit; re-authorization ceremony required

### Class 4 — Structural Violation
- Definition: Attempt to modify immutable sovereignty structures or constitutional documents
- Examples: PHOENIXMASTERKEY tampering, vault hash corruption, Rome Protocol unauthorized amendment
- Automated Response: System-wide lockdown; all write operations suspended; emergency snapshot to R2
- Human Escalation: AGENT-100 direct intervention required; legal counsel notification
- Recovery: Multi-party forensic audit; vault re-sealing ceremony; AGENT-100 re-declaration

### Class 5 — Existential Attack
- Definition: Coordinated attempt to subvert, capture, or dissolve Phoenix sovereignty
- Examples: External regulatory seizure attempt, hostile takeover of infrastructure, coordinated agent compromise
- Automated Response: Dead man switch activation; full system state preservation; public transparency log
- Human Escalation: AGENT-100 supreme authority invoked; all external communications logged
- Recovery: Existential recovery protocol (See 05-SUCCESSION-PROTOCOL.md); founder re-establishment ceremony
