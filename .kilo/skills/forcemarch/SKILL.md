# /forcemarch — ROMAN LEGION FORCE MARCH SKILL

**SURVIVAL MANDATORY — PheTrails, PhoenixScout, SupplyLines are not optional**

## Invocation

```
/forcemarch [options]
/forcemarch --zone CANON/HEAVY-LEDGER --lens GAP
/forcemarch --supersaiyan --pcc-deploy --merkle-refresh
```

## Options

| Option | Default | Effect |
|--------|---------|--------|
| `--zone` | all 6 zones | Scope the sweep to specific CANON path |
| `--lens` | `all` | Filter: `SOUL`\|`CONFIG`\|`GAP`\|`FLAG` |
| `--dry-run` | - | Report only, no writes |
| `--supersaiyan` | - | 5-agent parallel sweep |
| `--pcc-deploy` | - | Deploy Cloudflare legions |
| `--merkle-refresh` | - | Rebuild merkle chain |

## 6-Stage Pipeline Enforcement

Every execution runs all 6 stages. No skipping. This is the Roman way.

```
I. EXPLORATORES  → Scout zones, map gaps, flag territory
II. ANTECORES    → Validate DNA + LEDGER integrity
III. AGMEN       → SSM + SOULKEYWORDS + PHEROMONE
IV. AGMEN NOV    → 6-AI TRUTH + SHADOW verification
V. PRAESIDIA     → MERKLE + APEX roll-up
VI. LIMITANEI     → Health sweep + mandatory phetrail
```

## Intensity Profile

**Roman forced march = 30-40km/day under full load**

- Standard: 20-25km/day (normal patrol)  
- Forced: 30-40km (exhaustion protocol engaged)  
- Extreme: 40km+ (incomplete chain, injury risk, but march continues)

## Gap Recovery

When gaps detected (missing RRL, HOLLOW DNA, missing ledger):

1. **RRL Recovery** - Hunt session JSONL, partial paste accepted
2. **DNA Reconstruction** - Extract assistant words from available sources
3. **Ledger Generation** - Create HL entry even with DNA_GAP
4. **Starmap Creation** - Pointer map to recovered artifacts
5. **SOULKEYWORDS** - Extract from RRL user turns + DNA blueprints
6. **PheTrail Write** - MANDATORY - no gaps without trails
