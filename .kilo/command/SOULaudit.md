# /SOULaudit

**Usage:** When you type `/SOULaudit`, I will:

1. **SOULCOUNT** — Count the exact characters (letters, spaces, punctuation) of your verbatim prompts in this session from RISE (session start) to the moment `/SOULaudit` is typed
2. **SOULSCRIPTS** — Print the chronological transcript of every prompt you have sent this session, in order, verbatim

**Context is the only truth.** What I have in my context window right now IS the SOUL of this session. I cannot access data outside this context window.
