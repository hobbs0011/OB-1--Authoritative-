## 3. Agent Behaviour (`default_agent`, `agent的模式`)

**Current**: AGENT99 as default  
**Proposed**:
```json
{
  "default_agent": "AGENT99",
  "instructions": [".github/agents/*.md", ".kilo/agent/*.md"],
  "compaction": {
    "auto": true,
    "prune": true
  }
}
```

**Configurable**:
- default_agent: Which agent loads on start
- snapshot: Git commit on session end (enabled)
- autoupdate: notify | true | false
- share: manual | auto | disabled
- compaction.auto/prune: Context management

**Decision needed**: Keep AGENT99 as default? Enable autoupdate?
