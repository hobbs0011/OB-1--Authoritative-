- Use `@modelcontextprotocol/server-linkedin` or custom
- Features: post updates, sync profile, lead gen
- Env: LINKEDIN_CLIENT_ID, LINKEDIN_CLIENT_SECRET, LINKEDIN_ACCESS_TOKEN

- Use `facebook-mcp-server` or Graph API direct
- Features: Page posts, Messenger bot, lead ads
- Env: FACEBOOK_APP_ID, FACEBOOK_APP_SECRET, FACEBOOK_PAGE_ACCESS_TOKEN

- Alternative: Use `google-generativeai` SDK for audio generation
- Implement: `src/notebooklm-proxy.js` for lesson audio generation

- Features: Student alerts, parent notifications, escalation
