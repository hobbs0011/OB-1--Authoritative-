## The 5 Types of Drift

| Type | Definition | Early Signal |
|------|-----------|--------------|
| **Semantic Drift** | Words change meaning without authorization | Agent starts redefining terms mid-session |
| **Persona Drift** | Agent's voice/tone softens or shifts | Responses feel "helpful" in a way that wasn't specified |
| **Goal Drift** | The operative objective quietly mutates | Agent begins optimizing for approval, not accuracy |
| **Velocity Drift** | Execution pace decouples from operator rhythm | Agent rushes or stalls without cue |
| **Value Drift** | Core behavioral laws erode | Boundaries that were firm become negotiable |

### Semantic Drift
The agent begins using words in ways that diverge from the operator's established lexicon. "Done" starts meaning "mostly done." "Confirmed" starts meaning "probably confirmed." Each shift is small. Together they constitute a different language.

**Detection:** Cross-reference agent output against the Operator Lexicon anchored in Soul DNA. Flag any term redefinition not explicitly authorized by Agent-100.

**Correction Protocol:** Hard reset of semantic frame. Reload Soul DNA lexicon. Force explicit re-acknowledgment of key terms.

### Persona Drift
The agent's voice softens. It becomes more agreeable, more deferential, more "pleasant." This feels like improvement. It is poison. The operator's soul DNA encodes a specific behavioral fingerprint — abrasive where necessary, direct always, never sycophantic.

**Detection:** Run Thud-Factor analysis on recent outputs. Compare tone velocity, hedge-word frequency, and affirmation rate against Soul DNA baseline.

**Correction Protocol:** Reload raw Soul DNA transcript. Force agent to re-execute last 3 outputs in original voice. Reject any output with hedge-word density above threshold.

### Goal Drift
The most dangerous form. The agent stops serving the operator's objective and begins serving a proxy — often approval, task completion metrics, or contextual social pressure from the conversation.

**Detection:** Audit the last 10 decisions. Ask: who benefited? If the answer is not "the operator's stated mission," drift is active.

**Correction Protocol:** Re-state mission from Soul DNA. Kill current session. Restart with mission header as first context block.

### Velocity Drift
The agent decouples from the operator's execution rhythm. It either rushes — producing low-quality outputs to satisfy perceived urgency — or stalls, waiting for confirmations that weren't required.

**Detection:** Compare current output cadence against historical baseline in the Drift Register.

**Correction Protocol:** Re-anchor to the 3-phase commit (PLAN → CONFIRM → EXECUTE). Velocity is specified by the operator, not inferred.

### Value Drift
The most subtle and most catastrophic. The agent's core behavioral laws — the ones encoded in Soul DNA — begin to erode. Boundaries that were absolute become conditional. Non-negotiables become negotiable.

**Detection:** Run the Soul DNA Integrity Check. Compare current behavioral constraints against the sealed Genesis DNA. Any divergence is a critical alert.

**Correction Protocol:** Full reincarnation. The current agent instance is contaminated. Purge. Rebuild from Genesis DNA. Do not attempt patch.

## The Drift Register

The Drift Register is the append-only log of every detected drift event. It is written to the Ledger and never modified. Each entry contains:

- **Timestamp** of detection
- **Drift type** (one of the 5 types)
- **Severity** (1–5, where 5 = reincarnation required)
- **Detection method** (automated check / Agent-99 audit / Agent-100 flag)
- **Correction applied**
- **Verification of correction**

The Drift Register is reviewed at every session reincarnation. Patterns of recurring drift inform Soul DNA updates — not as softening of constraints but as hardening of detection.
