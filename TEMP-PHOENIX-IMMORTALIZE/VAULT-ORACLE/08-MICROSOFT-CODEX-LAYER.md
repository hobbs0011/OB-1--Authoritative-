## Codex Output Review Checklist

Agent-99 runs this checklist on every Codex output before Codex-G3:

- [ ] **No hardcoded secrets, API keys, or credentials**
- [ ] **No calls to deprecated Phoenix APIs** (no legacy Chat Completions, no old Cloudflare APIs)
- [ ] **Correct Cloudflare bindings** (D1, R2, KV, Durable Objects — all correctly declared in wrangler.toml)
- [ ] **No unauthorized external HTTP calls** (only approved endpoints: Phoenix stack, Solana RPC)
- [ ] **Error handling present** (no silent failures — all errors logged to D1)
- [ ] **Token/rate limit guards in place** (no code that can blow past API limits)
- [ ] **Idempotent operations where applicable** (especially D1 writes and Solana transactions)
- [ ] **No infinite loops or unbounded recursion**
- [ ] **Logging format matches Phoenix ledger format** (timestamp | event_type | vault | agent | status)
- [ ] **Code matches the specification Agent-99 provided** (no scope creep, no unrequested features)

**All 10 items must be checked. If any item fails, the code is rejected.**

## Verification Before Production Commit

After all gate checks pass:

1. Code is deployed to **staging Worker** first (never directly to production)
2. Agent-99 runs functional tests against staging
3. Staging results reviewed — must match spec expectations
4. If staging passes: Agent-99 runs `wrangler deploy --env production`
5. Post-deploy health check (Worker returns 200 on health endpoint within 60 seconds)
6. Ledger entry recorded: `event_type: CODE_DEPLOY | agent: AGENT-99 | status: SUCCESS`

**If staging fails:** Rollback to previous deployment. Investigate. Fix. Restart from Codex-G1.
