# CANON/CASE-STUDIES — Phoenix Rising Protocol

**Purpose:** This directory stores case studies that prove foundational principles of the Phoenix Rising system. These are NOT academic exercises — they are **AI reframing tools** designed to correct AI drift toward outdated mental models.

## Why Case Studies Matter

AI models project from training data that is inherently backward-looking (often 2019-2023 era patterns). When Michael debates strategy with AI agents, the AI's default assumptions are anchored to pre-AI-era realities:
- "Games take 3-6 months to build" (true in 2022, false in 2026 with AI)
- "One person can't run multiple products" (true pre-AI, false now)
- "Coding is the bottleneck" (was true, now Studio/3D/audio are the real bottlenecks)

These case studies exist to **snap AI agents back to 2026 reality** whenever they drift into outdated projections.

## How To Use

When an AI agent gives advice anchored to pre-AI assumptions:
1. Reference the relevant case study
2. The agent reads the full debate transcript and correction
3. The agent recalibrates to 2026 reality
4. Better advice follows
