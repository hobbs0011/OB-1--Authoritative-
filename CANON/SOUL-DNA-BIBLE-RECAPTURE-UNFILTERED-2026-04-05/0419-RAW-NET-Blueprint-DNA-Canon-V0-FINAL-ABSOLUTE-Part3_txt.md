9.1 WHAT IS STORYFLOW
────────────────────────────────────────────

StoryFlow is the FUTURE of NET (V4 and beyond).
It transforms lessons from linear content into adaptive NARRATIVE UNIVERSES.

TRADITIONAL LESSON:
Teacher → Content → Student (passive)
Same path for everyone

STORYFLOW LESSON:
Student → Action → Story Response → Adaptive Path
Different journey for each learner based on behavior


WHY STORYFLOW MATTERS:
✓ Addresses psychological barriers (fear, anxiety, volume)
✓ Makes learning feel like a game/story, not school
✓ Adapts to student personality in real-time
✓ Creates emotional investment in progress
✓ Turns abstract concepts (confidence) into concrete "forces"


9.2 THE METAPHYSICAL FORCES (Energy, Flow, Noise)
────────────────────────────────────────────

StoryFlow uses THREE COSMIC FORCES to gamify psychology:

FORCE 1: ENERGY (Purple)
────────────────────────────────────────────
Represents: Action, Speaking, Participation
Increases when: Student speaks out loud, participates actively, takes risks
Symbolizes: The "tiger voice" philosophy
Color: Neon Purple (#a855f7)

LOW ENERGY SYMPTOMS:
• Passive learning only
• Silent study
• Reading without speaking
• Watching without doing

HIGH ENERGY BENEFITS:
• Confidence builds
• Fluency improves
• Fear decreases
• Natural speech patterns


FORCE 2: FLOW (Gold)
────────────────────────────────────────────
Represents: Understanding, Context, Natural Rhythm
Increases when: Student understands context without translation, speaks naturally
Symbolizes: Natural acquisition, the "1-hour lifestyle"
Color: Gold (#f59e0b)

LOW FLOW SYMPTOMS:
• Translating every word
• Pausing constantly
• Overthinking grammar
• Mechanical speech

HIGH FLOW BENEFITS:
• Effortless comprehension
• Natural speech rhythm
• Contextual understanding
• Language feels automatic


FORCE 3: NOISE (Blue - The Antagonist)
────────────────────────────────────────────
Represents: Anxiety, Overthinking, Fear, Grammar Prison
Increases when: Student hesitates, translates, fears mistakes, stays silent
Symbolizes: The "elephant chain," learned helplessness
Color: Blue (ONLY used for this antagonist force)

HIGH NOISE SYMPTOMS:
• Fear of mistakes
• Low volume speaking
• Excessive translation
• Paralysis before speaking

DEFEATING NOISE:
• Active practice (builds Energy)
• Context learning (builds Flow)
• Safe environment
• Buddy support


THE BALANCE:
────────────────────────────────────────────

GOAL: Maximize Energy + Flow, Minimize Noise

When Energy + Flow > Noise:
✓ Student is confident
✓ Learning feels natural
✓ Progress accelerates
✓ Fear diminishes

When Noise > Energy + Flow:
❌ Student is stuck
❌ Learning feels hard
❌ Progress stalls
❌ May quit

StoryFlow TRACKS these forces and ADAPTS lessons accordingly.

  speak_below_volume_threshold: +4,
  skip_speaking_exercise: +6,
  long_pause_before_answer: +3,
  apologize_for_mistake: +4
};

// Noise naturally decreases when Energy/Flow increase
function updateForces(student, action) {
  if (energyActions[action]) {
    student.forces.energy += energyActions[action];
    student.forces.noise -= 2; // Energy counteracts Noise
  }
  if (flowActions[action]) {
    student.forces.flow += flowActions[action];
    student.forces.noise -= 1;
  }
  if (noiseActions[action]) {
    student.forces.noise += noiseActions[action];
  }
  
  // Clamp all values 0-100
  student.forces.energy = Math.max(0, Math.min(100, student.forces.energy));
  student.forces.flow = Math.max(0, Math.min(100, student.forces.flow));
  student.forces.noise = Math.max(0, Math.min(100, student.forces.noise));
}
