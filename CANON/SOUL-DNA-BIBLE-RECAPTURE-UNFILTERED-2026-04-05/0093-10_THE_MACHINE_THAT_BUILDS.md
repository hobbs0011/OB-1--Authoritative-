3. **Chaos Node** (Grok/Scout) — Adversarially tests every build
4. **Ledger Node** (Local/SQLite) — Records every action, every result, every drift

The loop:

**`BUILD → AUDIT → CHAOS TEST → LEDGER → BUILD (next iteration)`**
