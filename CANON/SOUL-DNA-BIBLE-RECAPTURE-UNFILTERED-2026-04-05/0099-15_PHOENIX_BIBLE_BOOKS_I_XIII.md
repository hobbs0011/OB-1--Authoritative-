## COMMAND LIBRARY

The Bible Builder operates on strict commands:

| Command | Syntax | Purpose |
|---------|--------|---------|
| **ASSEMBLE** | `ASSEMBLE [book_number] [version]` | Merge all sections into a single monolithic JS file |
| **MERGE** | `MERGE [book_A] + [book_B] INTO [new_book]` | Combine closely related books |
| **UPDATE** | `UPDATE [book].[section] WITH [content]` | Insert new content into a specific section |
| **DEPRECATE** | `DEPRECATE [book].[section] REASON [why]` | Mark section deprecated (never delete) |
| **OPTIMIZE** | `OPTIMIZE [book] FOR [target]` | Restructure for readability, searchability, or size |

**Versioning rules:**
- **Major** (1.0 → 2.0): Breaking changes or complete rewrites
- **Minor** (1.0 → 1.1): New sections or significant additions
- **Patch** (1.0.0 → 1.0.1): Small updates or corrections
