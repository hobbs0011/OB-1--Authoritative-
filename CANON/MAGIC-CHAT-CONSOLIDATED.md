### Onboarding Flow (State Machine)

```
boot → intro (ask name) → ask_city → ask_level → ask_goal → chat → wrap → chat...
```

1. **intro:** Collect student name
2. **ask_city:** Where do you live? (Vietnamese rescue at 1st struggle)
3. **ask_level:** A1-C1 numeric picker (Vietnamese rescue at 1st struggle)
4. **ask_goal:** Practice area — friends/food/jobs/travel/school (auto-pick at 2nd struggle)
5. **chat:** Natural conversation via DeepSeek LLM (5 rounds then pronunciation tips)
6. **wrap:** Pronunciation coaching → restart cycle

### Vietnamese Rescue Rope System

Canon principle: *"Vietnamese fallback when student drowns, pushes back to English fast."*

- Try English 3X
- On 3rd struggle, offer Vietnamese hint
- Then push back to English immediately
- Adaptive per-state tracking: `struggles[key]` counter per onboarding step
