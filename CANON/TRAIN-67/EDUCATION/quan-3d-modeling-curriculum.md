**Outcome:** Quan can independently generate production-ready 3D assets using AI tools

## Curriculum Structure

### Module 1: AI 3D Modeling Fundamentals (Weeks 1-2)
**Tool:** TripoSR (local, free)
**Objective:** Understand 3D modeling basics and generate first prototype assets from text prompts.

**Lessons:**
1. What is 3D modeling? Why AI-assisted?
2. TripoSR setup and first generation
3. Understanding 3D formats (GLB, OBJ, FBX)
4. Prompt engineering basics for 3D
5. Validating and iterating on generated assets
6. Importing assets into Roblox Studio

**Assessment:** Generate 5 prototype assets from text prompts, import into Roblox Studio.

### Module 2: Prompt Engineering for 3D Assets (Weeks 3-4)
**Tool:** Meshy AI Pro ($16/mo)
**Objective:** Master prompt engineering for production-ready assets with commercial rights.

**Lessons:**
1. Meshy AI Pro setup and subscription
2. Advanced prompt engineering techniques
3. Style consistency across asset sets
4. PBR textures and material properties
5. Batch processing and workflow optimization
6. Quality control and asset validation

**Assessment:** Generate 10 production-ready assets with PBR textures, pass quality review.

### Module 3: Workflow Automation & Batch Processing (Weeks 5-6)
**Tools:** 3D AI Studio + custom scripts
**Objective:** Execute full 60-80 asset pipeline independently for Train-67.

**Lessons:**
1. 3D AI Studio integration
2. Batch processing strategies
3. Automation with Python scripts
4. Asset pipeline management
5. Integration with game development workflow
6. Portfolio development and next steps

**Assessment:** Execute full asset generation pipeline, deliver 20 production-ready assets.

## Synergy Model

This curriculum is NOT generic. It is the EXACT workflow used to generate Train-67's 3D assets.

**How it works:**
1. Lane A (game asset pipeline) executes the workflow for Train-67
2. Each step is documented: prompts, parameters, outputs, refinements
3. Documentation is converted into lesson plans and exercises
4. Curriculum is deployed to Quan's student portal
5. Quan executes the SAME workflow, generating assets while learning
6. Quan's output directly contributes to game launch

**Benefits:**
- Quan learns by doing real project work (not toy examples)
- Lane B is a free byproduct of Lane A execution
- No additional curriculum development cost
- Quan's assets go directly into the game
- Real-world portfolio piece for Quan
