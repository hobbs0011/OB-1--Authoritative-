- Click "Start Speaking Test"
- Speak 3 sentences about yourself (2 minutes)
- Obi listens + corrects

### Step 3: First Report (You generate this)

## If It Fails (Be Ready)

**Scenario A: 0/10 return on Day 2**
- Your correction engine is broken or confusing
- Fix: Test it yourself. Have Obi correct YOUR English. Fix bugs.

**Scenario B: 5/10 return Day 2, but 1/5 by Day 7**
- Retention loop is weak (reminders not working, no social proof)
- Fix: Add daily streak counter, make progress visible, celebrate wins

**Scenario C: 7/10 return Day 7, but 0/7 convert**
- Value isn't clear or price is too high
- Fix: Lower price to 300k for month 2, add free 1-on-1 follow-up with you
