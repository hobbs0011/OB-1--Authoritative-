## 3.4 TYPOGRAPHY RULES

### DO's ✅
- Use Inter for 95% of all text
- Maintain consistent scale (use rem, not px)
- Keep line-height between 1.4-1.8 for body text
- Use gradient text for major headlines
- Add glow effects to interactive text
- Keep hierarchy clear (3-4 levels max per page)
- Use bold weights (700+) for emphasis

### DON'Ts ❌
- Don't use more than 2 font families per product
- Don't use font sizes below 12px (0.75rem)
- Don't use ALL CAPS for body text
- Don't use italic as primary emphasis (use bold instead)
- Don't mix too many font weights on one page
- Don't use decorative or script fonts (breaks professionalism)

# 4. LAYOUT SYSTEMS: THE ARCHITECTURE

## 4.1 THE 4-LAYER SYSTEM

### LAYER 1: DARK FOUNDATION
```css
body {
    background: #0f0f1a;
    /* Optional gradient variation: */
    background: linear-gradient(180deg, #0a0a0f 0%, #0f0f1a 100%);
}
```

**PURPOSE:** Base canvas, provides depth, reduces eye strain

---

### LAYER 2: ORGANIC BLOBS (AMBIENT DEPTH)
```css
body::before {
    content: '';
    position: fixed;
    top: -10%;
    left: -10%;
    width: 400px;
    height: 400px;
    background: radial-gradient(circle, #a855f7, transparent 60%);
    filter: blur(80px);
    opacity: 0.3;
    z-index: -1;
    animation: float 20s infinite alternate;
    pointer-events: none;
}

body::after {
    content: '';
    position: fixed;
    bottom: -15%;
    right: -10%;
    width: 500px;
    height: 500px;
    background: radial-gradient(circle, #f59e0b, transparent 60%);
    filter: blur(80px);
    opacity: 0.2;
    z-index: -1;
    animation: float 25s infinite alternate-reverse;
    pointer-events: none;
}

@keyframes float {
    0%, 100% { transform: translate(0, 0) scale(1); }
    33% { transform: translate(30px, -30px) scale(1.1); }
    66% { transform: translate(-20px, 20px) scale(0.9); }
}
```

**PURPOSE:**
- Creates ambient depth and dimension
- Adds visual interest without distraction
- Provides "glow-behind" effect for glass panels
- Subtle animation creates life and energy

**VARIATIONS:**
- Add 3rd blob (pink #ec4899) at center for complex layouts
- Adjust blur (60-100px) based on viewport size
- Vary opacity (0.15-0.35) for different moods

---

### LAYER 3: GLASS PANELS (CONTAINERS)
```css
.glass-panel {
    background: rgba(26, 26, 38, 0.7);
    backdrop-filter: blur(12px);
    -webkit-backdrop-filter: blur(12px); /* Safari */
    border: 1px solid rgba(168, 85, 247, 0.2);
    border-radius: 16px; /* or 1rem */
    box-shadow: 
        0 8px 32px rgba(0, 0, 0, 0.4),
        0 0 0 1px rgba(168, 85, 247, 0.1) inset;
    padding: 2rem;
    transition: all 0.3s ease;
}

.glass-panel:hover {
    transform: translateY(-4px);
    border-color: rgba(168, 85, 247, 0.4);
    box-shadow: 
        0 12px 48px rgba(0, 0, 0, 0.5),
        0 0 40px rgba(168, 85, 247, 0.15);
}
```

**PURPOSE:**
- Primary content containers
- Creates depth separation
- Allows blob glow to show through
- Interactive hover states

**VARIATIONS:**
- **Subtle glass:** `backdrop-filter: blur(8px)`, lower opacity
- **Strong glass:** `backdrop-filter: blur(16px)`, higher opacity
- **Large panels:** 24px border-radius
- **Cards:** 12px border-radius

---

### LAYER 4: CONTENT WITH GLOW (INTERACTIVE)
```css
.button-primary {
```

## 4.2 GLASSMORPHISM SPECIFICATIONS

### MINIMUM REQUIREMENTS (MANDATORY)
1. **Backdrop Blur:** ≥12px (minimum, can be higher)
2. **Semi-transparent Background:** RGBA with 0.5-0.8 alpha
3. **Border:** 1px with RGBA purple at 0.1-0.3 alpha
4. **Border Radius:** 12-24px (smooth, modern curves)
5. **Box Shadow:** Multi-layer for depth

### BLUR VALUES BY USE CASE
- **Small cards/chips:** 8-12px blur
- **Standard panels:** 12-16px blur
- **Large containers:** 16-20px blur
- **Modals/overlays:** 20-24px blur
- **Background blobs:** 60-80px blur (not glassmorphism)

### COMMON MISTAKES TO AVOID ❌
- Blur < 12px (looks cheap, unprofessional)
- Opaque backgrounds (kills the glass effect)
- No border (loses definition)
- Sharp corners (use 12px+ border-radius)
- Forgetting `-webkit-backdrop-filter` (Safari support)

## 4.3 SPACING & GRID SYSTEM

### SPACING SCALE (8px BASE)
```css
:root {
    --space-xs: 0.5rem;  /* 8px */
    --space-sm: 0.75rem; /* 12px */
    --space-md: 1rem;    /* 16px */
    --space-lg: 1.5rem;  /* 24px */
    --space-xl: 2rem;    /* 32px */
    --space-2xl: 3rem;   /* 48px */
    --space-3xl: 4rem;   /* 64px */
}
```

**USAGE:**
- Padding: Use lg (24px) for panels, md (16px) for cards
- Margins: Use xl (32px) between sections, lg (24px) between elements
- Gaps: Use md (16px) for grids, sm (12px) for dense layouts

---

### GRID SYSTEM
```css
.container {
    max-width: 1200px;
    margin: 0 auto;
    padding: 0 var(--space-lg);
}

.grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
    gap: var(--space-xl);
}

.flex-row {
    display: flex;
    gap: var(--space-md);
    align-items: center;
}
```

**BREAKPOINTS:**
- Mobile: < 640px
- Tablet: 640px - 1024px
- Desktop: > 1024px
- Wide: > 1440px

❌ "Transform your English in 7 days with our SECRET METHOD!"

### 5. SHOW, DON'T JUST TELL
❌ "We have amazing teachers!"  
✅ "Our teachers interrupt you mid-sentence — not to correct, but to celebrate your courage."

## 7.2 TONE VARIATIONS BY CONTEXT

### MARKETING (BOLD & MOTIVATING)
- Short, punchy sentences
- Active voice
- Direct address ("you")
- Challenge existing beliefs
- Paint clear before/after picture

> "You spent 10 years learning English in school. You can read. You can write. But when it's time to speak? Nothing comes out. That ends now. NET breaks the silence."

---

### TEACHING (SUPPORTIVE & CLEAR)
- Warm, encouraging
- Clear instructions
- Positive reinforcement
- Growth mindset language
- Celebrate mistakes

**EXAMPLE:**
> "Great job! You spoke for 30 seconds without stopping. That's confidence. Don't worry about that grammar mistake — we'll fix it naturally over time. Keep that Tiger energy!"

---

### SALES (CONSULTATIVE & HONEST)
- Listen more than pitch
- Ask diagnostic questions
- Present solutions, not products
- Acknowledge concerns
- No pressure, just clarity

**EXAMPLE:**
> "Let me ask you something: What happens when you try to speak English right now? Do words come out? Or does your mind go blank? <pause> That's what I thought. Here's why that happens..."

---

### CORPORATE (PROFESSIONAL & DATA-DRIVEN)
- Business language
- ROI focus
- Metrics and results
- Case studies
- Professional tone

**EXAMPLE:**
> "Companies investing in NET see a 300% increase in employee English confidence within 90 days. Our enterprise dashboard tracks individual progress, team metrics, and ROI in real-time."

## 7.3 WORD CHOICES

### ✅ USE THESE WORDS

**EMPOWERMENT:**

- Break free, escape, rise, emerge

**ACTION:**
- Speak, practice, build, grow, achieve

- Conversation, communication, fluency

**COMMUNITY:**
- Together, buddy, partner, community, tribe

**RESULTS:**
- Guaranteed, proven, measurable, real
- 90 days, 1 hour daily, 80% completion rate
- Confidence first, grammar second

### ❌ AVOID THESE WORDS

**OVERUSED EDU-JARGON:**
- Methodology, pedagogy, curriculum (use simpler terms)
- Optimize, leverage, synergy (corporate cringe)
- Revolutionary, innovative (show, don't claim)

**NEGATIVE LANGUAGE:**
- Failure, bad, wrong, stupid, impossible
- Can't, won't, never (unless reframing: "You'll never go back")
- Difficult, hard, complicated (makes learning scary)

**GENERIC CLAIMS:**
- Best, #1, top-rated (meaningless without proof)
- Easy, quick, fast (feels scammy)
- Perfect, master (sets unrealistic expectations)

**FALSE PROMISES:**
- Fluent in X days (dishonest)

- Secret method (gimmicky)
