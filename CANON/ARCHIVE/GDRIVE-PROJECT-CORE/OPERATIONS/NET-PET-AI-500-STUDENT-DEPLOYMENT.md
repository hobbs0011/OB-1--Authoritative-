## PART IV: THE FIRST DIAGNOSTIC EVENT PROTOCOL

### IV.A — Identifying Systematic Drift (Story Virus)

**Symptoms to Monitor:**

1. **Consistency Drop:** Gospel 444 renders correctly on 99% of devices on Day 1, then 85% by Day 5
   - **Root Cause:** Likely CSS token limit or font rendering issue on older Android
   - **Fix:** Reduce color palette; use system fonts; optimize asset size

2. **Phonetic Assessment Drift:** Students report correct pronunciation marked "incorrect" or vice versa
   - **Root Cause:** Deepgram Aura 2 confidence threshold miscalibrated; cultural phonetic variations not in training data
   - **Fix:** Adjust confidence threshold; add Vietnamese-specific phoneme training

3. **Accountability Network Failure:** Parent notification spam (>5 per day) or total silence despite high activity
   - **Root Cause:** Notification logic buggy; threshold calculations off
   - **Fix:** Cap notifications to max 1/day per parent; calibrate thresholds against baseline

4. **Ledger Desync:** Drone reports task "complete" but Ledger hash mismatches parent task record
   - **Root Cause:** Race condition in write-ahead log; D1 SQLite transaction isolation issue
   - **Fix:** Add explicit transaction locks; validate hash before marking complete

### IV.B — The Fix Principle Protocol

**Never Patch Symptoms. Fix Root Cause Once, Fix It Forever.**

**Protocol:**
1. **Stop:** Halt affected drones; isolate anomalous subset
2. **Capture:** Extract exact parameters that triggered failure
3. **Isolate:** Run 100 simulations in Shadow Realm with identical inputs
4. **Root Cause:** Determine exact instruction path or logic gate that failed
5. **Minimal Fix:** Apply surgical correction to core logic (not a band-aid)
6. **Validate:** Run same 100 simulations; confirm 100% success
7. **Generalize:** Extend fix to all similar patterns in system
8. **Ledger Write:** Document as append-only diagnostic event with fix rationale
9. **Communicate:** Notify all drones of new rule; update templates

**Example:**
- **Symptom:** Phonetic assessment mislabels x% of Vietnamese tones
- **Root Cause:** Deepgram model was trained on American English; Vietnamese tonal variations not in training corpus
- **Fix (NOT):** "Lower confidence threshold to 0.7 instead of 0.8" (band-aid)
- **Fix (YES):** "Deploy separate phoneme classifier for Vietnamese tones; weight Deepgram output 60%, Vietnamese classifier 40%" (root cause addresses training data gap)
- **Generalize:** All SEA languages get same hybrid classifier treatment
- **Ledger:** "Diagnostic: Phonetic assessment drift detected Day 5. Root cause: Monolingual training data. Solution: Language-specific classifier hybrid. Applied to all SEA languages. Validated 100% success on 1000-iteration test."
