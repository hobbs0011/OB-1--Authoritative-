### 3.2 Data Flow (1-Second Cycle)

```
1. Student opens OBI chat
   ↓
2. Speaks: "I think sink is difficult"
   ↓
3. Browser STT converts to text
   ↓
4. Cloudflare Worker receives request
   ↓
5. Loads ProfileDO:
     Level: B1
     Top weakness: /θ/ sound
     Streak: 5 days
   ↓
6. Loads SessionDO (today's activity)
   ↓
7. Loads LedgerDO (verify integrity)
   ↓
8. Builds OBI prompt:
     System: "You are a teacher named Obi..."
     Context: "Student has /θ/ weakness (3x failure)"
     User: "I think sink is difficult"
   ↓
9. Calls DeepSeek (~300ms)
   ↓
10. DeepSeek returns:
    {
      correction: "We say: I think the SINK...",
      why: "The 'th' sound is pronounced between teeth",
      drill: "Repeat: think, thank, sink, thick",
      severity: 0.7
    }
   ↓
11. Worker updates memories:
    - SessionDO ← add correction
    - ProfileDO ← update weakness
    - LedgerDO ← append event
   ↓
12. Formats for TTS output
   ↓
13. Returns to browser (~700ms total)
   ↓
14. Browser plays correction aloud
   ↓
15. Student repeats drill
   ↓
16. Streak increments to 6
   ↓
17. Next day: "Your 6-day streak is waiting!"
```

**Total latency:** < 1 second  
**Total cost:** < $0.005
