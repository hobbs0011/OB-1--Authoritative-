## 📞 FAQ: Before You Deploy

**Q: Do I need to change the OBI prompt?**  
A: No. It's fine as-is. You can tweak it later based on user feedback. Ship first.

**Q: Should I add voice input before deploying?**  
A: No. Text works. Add voice after you have 50 users.

**Q: Is the database schema locked?**  
A: You can add fields to `prisma/schema.prisma` anytime. Run `npx prisma db push` again.

**Q: Will this scale?**  
A: Yes. Vercel + Postgres handles 10k+ concurrent users easily. That's 2–3 years of growth.

**Q: Can I monetize immediately?**  
A: Yes. Set up Stripe in Week 2. For now, manual transfers are fine for first 50 users.
