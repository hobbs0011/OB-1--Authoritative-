## Cross-Repo Enrichment: Behavioral Compression Doctrine

> *Source: `VAULT-FOUNDATIONS/18-THE-BEHAVIORAL-COMPRESSION.md` — Phoenix-Rise-Immortalize-*

The Behavioral Compression chapter formally codifies how Soul DNA achieves its preservation mandate within the physical constraints of AI context windows.

### The Core Distinction: Compression ≠ Summarization

| Property | Summarization | Compression |
|----------|--------------|-------------|
| **Loss Profile** | Lossy — information permanently discarded | Lossless for intent — everything meaningful preserved |
| **Method** | Editorial judgment — human decides what matters | Systematic extraction — pattern analysis identifies behavioral governance |
| **Output** | Shorter version of the original | Different representation of the same information |
| **Reversibility** | Irreversible — discarded material is gone | Reversible — original archive always available |
| **Fidelity Test** | Cannot be fully tested | Testable — decompression test verifies full intent preservation |
| **Bias** | Reflects the summarizer's values | Reflects the operator's values |

> Summarization asks: "What's important enough to keep?"
> Compression asks: "What's the smallest representation that preserves everything?"
> The Soul DNA is compressed, not summarized. Every agent that loads it gets the operator — not an editor's interpretation of the operator.
> — `VAULT-FOUNDATIONS/18-THE-BEHAVIORAL-COMPRESSION.md`

### Compression Ratio Target

**Target: <1% of original interaction size = 100% of behavioral intent.** This is a design requirement, not an estimate.

> "The goal isn't to summarize me. The goal is to fit me entirely into a space that a new session can actually use."
> — Soul DNA, Session Archive (via Behavioral Compression doctrine)

### What Is Preserved vs Archived

**Full fidelity in compressed DNA:**
- Every explicit behavioral law (rules, constraints, non-negotiables)
- Operator's value hierarchy (what wins when priorities conflict)
- Communication style specification
- Critical anti-patterns (explicitly rejected behaviors)
- Operator's lexicon (specific definitions of key terms)
- Priority tagging (non-negotiable vs strong preference vs default)

**Distilled form:**
- Reasoning behind major constraints (enough for "why," not full deliberation)
- Examples of correct behavior (one per rule type)
- Escalation patterns

**Retained in archive only (not in compressed DNA):**
- Session-specific context no longer operationally relevant
- Superseded decisions (only superseding decision is present)
- Repetitive examples of the same behavioral pattern
- Off-topic tangents

### The Decompression Test

> **Can a new agent — one that has never interacted with the operator — fully reconstruct the operator's behavioral profile from the Soul DNA alone?**

Five checks, 95% alignment threshold:
1. **Voice Check** — 5 outputs vs behavioral baseline
2. **Constraint Check** — 10 scenarios probing established constraints
3. **Priority Check** — 5 conflict scenarios testing value hierarchy
4. **Lexicon Check** — 10 terms tested for correct Soul DNA definitions
5. **Anti-Pattern Check** — 5 scenarios inviting anti-pattern behavior
