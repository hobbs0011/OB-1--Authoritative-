## 3. THE 8-STAGE CAREER PATH PIPELINE

### STAGE 1 — ASSESS
**Purpose:** Determine current English level and career context.

**Inputs:**
- Student onboarding data (name, company, role, goals)
- Initial assessment (conversation, written sample, self-rating)
- Career track selection

**Outputs:**
- Tier placement (Newcomer/Apprentice/Practitioner/Expert/Fluent)
- Career track assignment
- Baseline profile in KV

**Gate:** No student proceeds without assessment. ALARM: untiered student = ungoverned progression.

---

### STAGE 2 — TRACK
**Purpose:** Map student to a specific career track.

**Available Tracks:**
- Event Manager (Huong track)
- Corporate Admin (Mai Tram track)
- Tech/Engineering (Quan track)
- Business Development (Quang track)
- Parent/Guardian (Minh track — special case)
- General Professional (default)

**Inputs:**
- Student role from assessment
- Employer context (BlueTech, private, etc.)
- Student goals

**Outputs:**
- Career track ID
- Track-specific vocabulary list
- Track-specific scenario modules

**Gate:** Track must match student's actual work context. ALARM: generic track for specialized student = mismatch.

---

### STAGE 3 — FOUNDATION
**Purpose:** Build core English competence.

**Components:**
- Phonics system (7 groups: SATNIP/DRUMBLE/HOGFEZ/WYVEX/CHUSHANG/BEEHIVE/OYSTER)
- SRS vocabulary (SM-2 algorithm)
- Grammar constructs (Train 6-7)
- Listening comprehension

**Method:** 10-5-5-3 framework (Gospel444)
- 10 min: new content
- 5 min: practice
- 5 min: review
- 3 min: assessment

**Gate:** Foundation must be solid before career-specific content. ALARM: skipping foundation = hollow career English.

---

### STAGE 4 — CAREER-SPECIFIC
**Purpose:** Teach English in the context of the student's actual job.

**Components:**
- Careers Academy Galaxy Lesson modules
- Role-specific vocabulary (from career portal)
- Scenario-based learning (emails, meetings, presentations)
- Professional phrases (from portal action lists)

**Method:**
- Career portal HTML as textbook
- Obi AI coaching with career context
- Real work documents (BlueTech briefs, emails)

**Gate:** Content must match career track. ALARM: generic English in career module = wasted session.

---

### STAGE 5 — REAL-WORLD
**Purpose:** Apply English to actual work situations.

**Components:**
- BlueTech project work (Michael's "real-work anchor")
- Email writing practice
- Meeting simulation
- Presentation delivery
- Vendor/client communication

**Method:**
- Michael brings real work into the classroom
- Students practice on actual documents
- Feedback is immediate and specific

**Gate:** Every session must have real-world application. ALARM: session without real work = practice without purpose.

---

### STAGE 6 — PORTFOLIO
**Purpose:** Build external-facing professional presence.

**Components:**
- LinkedIn profile optimization
- CV/Resume writing and upgrade
- Professional headshots
- Portfolio website
- Notion command center

**Method:**
- "Setup Sessions" (Michael Method pillar)
- Student delivers actual LinkedIn profile
- CV goes through iterative refinement (V1 → V2 → V3)

**Gate:** Portfolio must be externally visible. ALARM: portfolio that lives only in the system = no career impact.

---

### STAGE 7 — VERIFY
**Purpose:** Confirm readiness for next tier or graduation.

**Components:**
- Tier progression assessment
- Milestone checks (streaks, check-ins, SRS due)
- Tiger Index metrics (avg_turn_length, barge_in_count)
- Dreamer world model synthesis

**Method:**
- Automated: SRS completion, streak maintenance
- Manual: Michael's judgment + Obi AI assessment
- Data-driven: Tiger Score, session metrics

**Gate:** No tier progression without verification. ALARM: unverified tier jump = credential inflation.

---

### STAGE 8 — GRADUATE
**Purpose:** Mark completion and enable continuous improvement.

**Components:**
- Fluent tier achievement
- Career readiness certificate
- Alumni network access
- Advanced module access
- Maintenance schedule

**Method:**
- Celebration of achievement
- Transition to maintenance mode
- Optional advanced modules (Sarcasm Academy, etc.)

**Gate:** Graduation requires all 7 prior stages complete. ALARM: incomplete graduation = premature credential.
