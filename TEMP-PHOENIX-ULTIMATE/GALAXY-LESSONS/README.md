## Gospel 444 Format

Every lesson follows the Gospel 444 structure:
- **4 sections** per lesson
- **4 difficulty levels** (Mouse → Cub → Wolf → Tiger)
- **4 interaction types** per section
- Vietnamese subtitles and vocab tooltips throughout
- Mobile-first responsive design
- Void black / purple / gold color scheme (NO BLUE)

## Adding Lessons

1. Create an HTML file following the Gospel 444 template
2. Name format: `NET-{Topic}.html`
3. Include Vietnamese subs and tooltip vocabulary
4. Test on mobile viewport before committing
