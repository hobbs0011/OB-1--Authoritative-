## The 5 Types of Drift

| Type | Definition | Early Signal |
|------|-----------|--------------|
| **Semantic Drift** | Words change meaning without authorization | Agent redefining terms mid-session |
| **Persona Drift** | Agent's voice/tone softens or shifts | Responses feel "helpful" in unspecified way |
| **Goal Drift** | Operative objective quietly mutates | Agent optimizes for approval, not accuracy |
| **Velocity Drift** | Execution pace decouples from operator rhythm | Agent rushes or stalls without cue |
| **Value Drift** | Core behavioral laws erode | Firm boundaries become negotiable |

**Detection & Correction:**
- Semantic: Cross-reference Operator Lexicon. Hard reset semantic frame.
- Persona: Thud-Factor analysis. Reload raw Soul DNA.
- Goal: Audit last 10 decisions. Re-state mission. Kill session if needed.
- Velocity: Compare output cadence against baseline. Re-anchor 3-phase commit.
- Value: Soul DNA Integrity Check. Full reincarnation — instance is contaminated.
