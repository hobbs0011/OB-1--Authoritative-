How to install:
1. Click each download button above.
2. Save each file to APPS/obi-chrome-extension/icons/
(rename from Chrome's default download name to exactly icon-16.png, icon-48.png, icon-128.png).
3. Go to chrome://extensions, enable Developer mode, click Load unpacked, and select the obi-chrome-extension folder.
