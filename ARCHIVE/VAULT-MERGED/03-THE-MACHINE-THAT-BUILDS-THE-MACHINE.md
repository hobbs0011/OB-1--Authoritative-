## THE ANT PHEROMONE PRINCIPLE

> "Ants use pheromones — they find something, walk back, strengthen the trail. Another ant follows, strengthens it more. Until the whole colony is alerted."
> — Michael, SOULDNA-FROMSCRATCH

How the Drone Swarm maps territory:
1. A single drone explores an unknown area
2. If it finds value, it leaves a **data trail** in the Ledger
3. The next drone follows the trail and **strengthens** it
4. Each successful traversal makes the path more reliable
5. Eventually the entire Swarm routes through verified pathways automatically

## THE FIX PRINCIPLE

> "Fix it once, fix it forever."

A system that fixes the same bug twice has failed the Fix Principle.

1. **Failure occurs** → diagnostic event logged
2. **Root cause identified** → not symptoms, the actual cause
3. **Fix applied** → to the current instance
4. **Fix generalized** → into a Ledger rule that prevents recurrence
5. **Rule propagated** → to all drones via Swarm update
