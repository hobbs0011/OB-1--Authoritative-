# OBI Extension Icons

Place your extension icons here:

- `icon16.png` — 16x16px (toolbar)
- `icon48.png` — 48x48px (extensions page)
- `icon128.png` — 128x128px (Chrome Web Store)

## Design Guidelines

- Use the OBI speech bubble emoji or custom logo
- Primary color: #f59e0b (amber/gold)
- Background: #0f172a (dark slate) or transparent
- Keep it simple and recognizable at 16px

## Quick Generate

You can generate these from any image using:
- [favicon.io](https://favicon.io)
- [realfavicongenerator.net](https://realfavicongenerator.net)

Or use a simple canvas script to generate from emoji.
