About

NET is a premium bilingual English training brand based in Vietnam. We run human-reviewed assessments, AI-forward curricula, and confidence-building programs for learners from age 3 to professional adulthood.

Programs

  • NET Tigers — Ages 8–17, speaking confidence, phonics, writing
  • NET Cubs — Ages 3–7, foundational phonics and play
  • NET Professionals — Adults, career English + AI mastery
  • NET University — Admission prep and academic writing
  • NET Career — Vocational pathways and job-ready English

Tech

Frontend lives on Cloudflare Pages. Backend runs on Workers + D1. Assessment data is captured client-side and submitted via submission-api.

git clone https://github.com/naturalenglishtraining/dashboard.git
cd dashboard
npm install
npm run dev

NET-Tigers

Ages 8–17 · Speaking confidence, phonics, writing, and reading fluency.

42 Phonics Sounds
5 Assessment Parts
24h Human Review

Curriculum Overview

NET Tigers uses a human-reviewed assessment pipeline. Every submission is listened to by Michael personally — no algorithmic scoring. The program covers phonics (42 Jolly Phonics sounds), reading fluency, writing range, and free speaking.

Assessment Structure

  • Part 1: About You — identity and learning context
  • Part 2: Jolly Phonics — 42 core sounds across 7 groups
  • Part 3: Reading — three passages + comprehension
  • Part 4: Writing — 5 open-ended prompts
  • Part 5: Free Speaking — 30–60 seconds on any topic

Output

After completion, families download a submission pack. NET reviews within 24 hours and books a free trial class — in-person in Lakeview City or video call worldwide.
