# Battle Pass Season 1: "Brainrot Apocalypse" — Design Spec
> Train-67 | Created: 2026-03-28 | Status: READY FOR COPILOT
> Priority: 🔴 BEFORE LAUNCH | Pipeline Stage: 8

## OVERVIEW
- **Season Name:** Brainrot Apocalypse
- **Duration:** 30 days from launch
- **Tiers:** 50
- **Free Track:** Rewards every 5 tiers (10 free rewards)
- **Premium Track:** 499 R$ — rewards every tier (50 premium rewards)
- **Tier Skip:** 75 R$ per tier
- **XP Per Tier:** 1,000 BP XP (scales: Tier 1-10 = 800, Tier 11-30 = 1,000, Tier 31-50 = 1,200)

## XP SOURCES

| Source | BP XP | Frequency |
|--------|-------|-----------|
| Daily Login | 50 | Daily |
| Kill Zombie | 1 | Per kill |
| Kill Boss | 100 | Per boss |
| Daily Challenge (easy) | 100 | 3/day |
| Daily Challenge (hard) | 200 | 1/day |
| Weekly Challenge | 500 | 3/week |
| Survive 10 Days | 150 | Per milestone |
| Complete Day 99 | 1,000 | Per completion |
| Win 1v1 Arena Match | 75 | Per win |
| Trade 5 Items | 50 | Daily cap |

**Target:** Casual player (30 min/day) reaches Tier 35 by season end. Dedicated player (1hr/day) reaches Tier 50. This creates incentive to buy tier skips for casuals.

## REMOTE EVENTS

```lua
-- Server → Client: BP State
BattlePassState:FireClient(player, {
    currentTier = number,
    currentXP = number,
    xpToNextTier = number,
    isPremium = boolean,
    claimedRewards = {}, -- tier numbers already claimed
    challenges = {
        daily = id, description, progress, target, xp, isHard,
        weekly = id, description, progress, target, xp
    }
})

-- Client → Server: Claim Reward
ClaimBPReward:FireServer({tier = number, track = "free"|"premium"})

-- Client → Server: Buy Premium
BuyPremiumPass:FireServer() -- triggers 499 R$ purchase

-- Client → Server: Skip Tier
SkipTier:FireServer({count = number}) -- triggers 75 R$ × count purchase

-- Server → Client: Challenge Complete
ChallengeComplete:FireClient(player, {
    challengeId = string,
    xpEarned = number,
    newTier = number -- if leveled up
})
```

## SEASON TRANSITION

When Season 1 ends:
1. All unclaimed FREE rewards become claimable for 7 more days
2. All unclaimed PREMIUM rewards become claimable for 7 more days
3. Tier 50 Scythe becomes UNTRADEABLE
4. Season 1 codex entries lock (any missed = gap forever)
5. BP resets to Tier 0
6. Season 2 BP becomes available (499 R$ for premium)
7. New challenges, new rewards, new theme
