# SexonDex Landing Page Clone

## What Was Built

A cinematic, tab-based landing page for **SexonDex** — a licensed dispensary selling Dexedrine and sexual health medicines.

## Tech Stack
- Pure HTML/CSS/JS (no dependencies)
- Glass morphism + dark cinematic theme
- GSAP-style scroll animations (vanilla JS)
- Responsive mobile design
- Cloudflare Pages ready

## Features
- **4 Tabs:** Home (Landing), Products, About, Contact
- **Cinematic hero** with particle effects and gradient animations
- **6 product cards** with hover effects
- **Scroll-triggered animations**
- **Contact form** with validation
- **Keyboard shortcuts** (1-4 for tabs)
- **Default view:** Landing tab

## Files
- `index.html` — Complete single-file app (~980 lines)

## Deploy to Cloudflare Pages

### Option 1: Direct Upload
1. Zip the `sexondex/` folder
2. Go to [dash.cloudflare.com](https://dash.cloudflare.com) > Pages
3. Create project > Direct upload
4. Upload zip and deploy

### Option 2: Git Connect
1. Push this folder to a GitHub/GitLab repo
2. Connect repo in Cloudflare Pages
3. Build command: (leave empty)
4. Output directory: `/`
5. Deploy

## Live URL
After deployment, your site will be available at `https://sexondex.pages.dev` (or your custom domain).
