## Solana Payment Integration

Solana was selected as the payment infrastructure because:
- **Immutability**: On-chain transactions cannot be reversed
- **Speed**: 400ms finality aligns with the 444ms Heartbeat cadence
- **Sovereignty**: No bank, no intermediary, no permission required

Payment flow:
1. Agent-99 generates payment request with amount, student ID, and course ID
2. Customer wallet signs and broadcasts transaction
3. Agent-99 monitors Solana for transaction confirmation
4. On confirmation: Revenue Ledger entry created with transaction hash
5. Transaction hash + Ledger entry hash = cryptographic proof of payment

## Revenue Ledger

The Revenue Ledger is a dedicated Ledger shard that records every financial event:

- Course enrollment payments
- Corporate contract payments
- Franchise license fees
- Refunds (if ever issued — recorded as negative entries, never deleted)
- Revenue milestone events

The Revenue Ledger is immutable. No entry is ever deleted. Financial history is permanent.
